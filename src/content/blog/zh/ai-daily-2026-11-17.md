## 11 月 16 日：Qwen4-Max 从预览转向正式供给

阿里云 11 月 16 日公告称，Qwen4-Max 已通过 QwenCloud 套餐和 API 提供，支持原生视觉和百万 Token 上下文。归档的预览文档另载明，预览期从 11 月 11 日开始；此次正式发布不能与预览开放合并成同一时间点。

公告称，在内部 Work360 测试中，相较 Qwen3.8-Max，High 推理档的 Token 使用量减少 35%，平均单任务成本下降约 60%。这些数字属于厂商特定评测，不能直接换算为所有工作流或用户账单的节省比例。

同一公告将较小的开放权重模型列为后续计划。正式 API 可用、预览服务条件和可下载模型权重是三个不同问题；本文确认的是归档公告的范围，没有做硬件部署或横向基准测试。

## 11 月 16 日：百度披露第三季度 AI 云增长

百度 11 月 16 日发布第三季度业绩，披露 AI Cloud Infra 收入为 82 亿元人民币，同比增长 94%。其中 GPU Cloud 收入同比增长 191%、环比增长 43%；这些口径来自公司业绩公告。

公司还披露第三季度经营现金流为 28 亿元人民币，并描述客户结构更分散、预付款增加和合约期限延长。AI Cloud Infra 是特定业务口径，不能将其 94% 增速当作集团整体收入增速。

这些披露为观察 AI 基础设施需求提供了收入和合同层面的信息，但没有给出每个客户的实际推理效果或投资回报。本文没有独立审计财务数据，也不据此推断某一种模型或算力采购方案更优。

[来源 S03](<https://ir.baidu.com/news-releases/news-release-details/baidu-announces-third-quarter-2026-results>)

## 11 月 16 日：Hugging Face 更换语言模型推理路由

Hugging Face 与 OpenRouter 的公告说明，语言模型请求改由 OpenRouter 根据实时价格、速度和可靠性选择提供商，并在一次调用中支持失败切换。OpenRouter 的公告明确标注 11 月 16 日；现有 Hugging Face Token 和调用代码可以沿用。

兼容接口不代表所有账户行为都不变。该路径的语言模型请求由 Hugging Face 账户或组织计费，不再支持用户自带提供商 API 密钥；用户仍可指定提供商或在设置中禁用提供商。

图像、视频和音频生成继续通过原有 Hugging Face Inference Providers 路径，不经过 OpenRouter。因而这是有范围的路由和计费迁移，不宜写成整个平台迁移；本文未测试故障切换成功率或不同供应商的数据处理行为。
