## Bot / Attack Traffic

The site receives significant automated scanning traffic, mostly targeting WordPress vulnerabilities:

**Common attack patterns seen (each getting 4-30+ requests/day):**
- `wp-admin/install.php` — WordPress install scanning
- `wp-content/plugins/hellopress/wp_filemanager.php` — Plugin exploit probes
- `wp-content/themes/` — Theme vulnerability scanning
- `.env`, `.env.backup`, `.env.prod` — Credential hunting
- `.git/config` — Git repository exposure probes
- `api/.env`, `key.json`, `credentials.json` — Secret scanning
- Various PHP webshell probes (`x.php`, `1.php`, `admin.php`, `shell.php`, etc.)
- `sitemap.xml`, `robots.txt` — Reconnaissance

**Note:** These inflate the "total requests" count significantly. Page Views is a better indicator of real human traffic. The `/favicon.ico`, `/robots.txt`, and static asset requests are normal.
